This module adapts the e-mails sent by the Calendar (invitation, date change,
reminder and event update) to the Armazem de Documentos visual identity:

* the e-mails are wrapped in a layout with the company logo, the green header
  border and the dark green footer with the company phone, e-mail and website;
* the templates use the company green instead of the Odoo purple;
* the texts and buttons are written in Brazilian Portuguese.
